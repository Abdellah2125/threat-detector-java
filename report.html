١. الملخص التنفيذي

تطبيق Threat Detector هو إعادة كتابة مستقلة بالكامل بلغة JavaFX لأداة كشف تهديدات كانت مبنية أصلاً بتقنية Rust/Tauri وواجهة React. يهدف المشروع إلى الحفاظ على الهوية البصرية للواجهة القديمة مع تنسيق الألوان وتنظيم الشاشات بطريقة احترافية، وتنفيذ متطلبات Sprint 01 حرفياً: واجهة JavaFX، قواعد محلية، وتعدد خيوط حقيقي.

17قاعدة كشف 4خيوط عمل 52اختباراً ناجحاً 0اتصال شبكي

يعمل التطبيق محلياً بالكامل. يُدخل المستخدم إما رابطاً أو رسالة واحدة، أو يحمّل ملف CSV للفحص الدفعي. تُقيَّم كل إشارة بمجموعة قواعد حتمية، ويُنتج عن ذلك درجة من 0 إلى 100 ومستوى خطورة LOW / MEDIUM / HIGH، أو حالة مستقلة هي Not Verified عند تعذّر التحقق. الواجهة لا تحسب أي درجة بنفسها، بل تستدعي طبقة تنسيق تُسمى ScanCoordinator.

الجاهزية: متطلبات Sprint 01 الأساسية مكتملة ومُختبرة بالكامل. الميزة الإضافية (AI explanation) مُهيكلة كواجهة قابلة للتوصيل فقط، لا تغيّر النقاط، ولذلك تُقيَّم كـ «جزئية» في مصفوفة المتطلبات.

٢.٣ القرارات التصميمية

  • اختيار Option A بدل API خارجي: لا مفاتيح API، لا حدود معدل، لا اتصالات HTTP، ونتائج قابلة لإعادة الإنتاج.
  • استخدام JavaFX SubScene وPerspectiveCamera بدل Three.js/WebGL لمشهد العمليات ثلاثي الأبعاد.
  • تغليف المنطق في خمس حزم: model, detection, intake, runtime, ui.
  • اعتبار Not Verified حالة مستقلة لا تُحوَّل أبداً إلى LOW.

٣. البنية العامة وتدفق البيانات

٣.١ المخطط الطبقي

UI (JavaFX) → runtime (ScanCoordinator / ScanEngine / Services) → detection (RuleSet / Rules / Scoring) → model (Records) intake (CsvLoader) → model (LoadedRow / CsvLoadReport) → runtime.scanBatch
الحزمة الدور القاعدة الذهبية
model سجلات بيانات غير قابلة للتعديل، أنماط، أحداث. لا منطق كشف ولاooks واجهة.
detection القواعد، الكتالوج، التحقق من المدخل، النقاط. دوال نقية وحتمية قدر الإمكان.
intake قراءة CSV وتحويله إلى صفوق مُتحقَّق منها. لا يستدعي محرك القواعد مباشرة.
runtime التنسيق، التقييم، التزامن، محاكاة الأخطاء، الشرح الاختياري. النقطة الوحيدة التي يستدعيها-thread الواجهة.
ui العرض، التفاعل، المشهد 3D، جسر الأحداث. لا تحسب درجات وتُحدّث الواجهة عبر Platform.runLater.

٣.٢ تدفق الفحص المفرد

  1. المستخدم يختار URL أو Message ويُدخل النص أو يضغط إحدى البطاقات الثلاث.
  2. CheckPanel يتحقق من الفراغ والطول ثم يستدعي bridge.onReset().
  3. على خيط daemon باسم check-scan يُستدعى coordinator.scanSingle(...).
  4. ScanEngine يوزّع العنصر على عامل من مسبح 4 خيوط، فيستدعي LocalRuleEvaluationService.
  5. RuleSet يُحلّل المدخل ويُشغّل القواعد، ثم Scoring.finalize يُنتج الدرجة والمستوى.
  6. ScanUiBridge يبث الأحداث إلى الواجهة، فتُحدَّث المؤشرات والمشهد ثلاثي الأبعاد وبطاقة الحكم.

٣.٣ تدفق الفحص الدفعي

يُختار الملف من Bulk scan → Choose file، فيقرأه CsvLoader وُنتج CsvLoadReport يحوي صفوفاً صالحة وأخرى تحمل مسبقاً NotVerified / INVALID_CSV_ROW. ثم يمرّ التقرير إلى ScanCoordinator.scanBatch الذي يحوّل الصفوف إلى عناصر عمل، ويغلّف المُقيِّم بحيث تُعاد النتيجة المسبقة للصفوف غير الصالحة دون تقييمها مجدداً.

٤. منهجية الكشف والتقييم

٤.١ الفرق بين الخيار الأول والثاني

وجه المقارنة Option A — المستخدم فعلياً Option B — مُモデルَج فقط
الصنف LocalRuleEvaluationService ExternalApiEvaluationService
المصدر قواعد Java محلية عبر RuleSet. خدمة خارجية مفترضة بلا طلب HTTP حقيقي.
المخرج Scored(score, risk, findings) أو NotVerified لأسباب الإدخال. يرمي CheckUnavailableException في كل الأوضاع، فيُحوَّل إلى NotVerified.
الشبكة والمفتاح لا شيء إطلاقاً. يحاكي API_KEY_MISSING وAPI_RATE_LIMITED وAPI_TIMEOUT وAPI_INVALID_RESPONSE.
الحالة في البناء مُفعّل افتراضياً في ScanCoordinator. موجود لإثبات معالجة الأخطاء فقط.
حتى وضع AVAILABLE في الخيار الثاني يرمي CHECK_UNAVAILABLE، لأن البناء صُمِّم offline. بهذا لا يُفترض أن «غياب التحقق = أمان».

٤.٤ نظام النقاط والمستويات

مجموع نقاط القواعد المُشترِطة → قصّ عند 100 واقتطاع سالب إلى 0 → التصنيف
الدرجة المستوى الدلالة في الواجهة
60 – 100 HIGH إشارات عدائية واضحة — «Hostile signals».
25 – 59 MEDIUM يستوجب المراجعة — «Review before trusting».
0 – 24 LOW لا قواعد مهمة — ليس ضمان أمان.
غير محسوبة NOT VERIFIED تعذّر التحقق — حالة مستقلة وليست منخفضة.

٥. استيعاب الدفعات عبر CSV

يُقرأ الملف بترميز UTF-8، ويُقبل الرأس type,target Ignoring للحالة، مع دعم BOM والفاصلة داخل الخلايا المقتبسة وعلامة الاقتباس المهرّبة "". الأنواع المقبولة هما url وmessage فقط.

الحد القيمة السلوك عند التجاوز
حجم الملف 5 ميغابايت LoadException ويُعرض شريط خطأ.
صفوف البيانات 5000 صف LoadException.
التحذيرات المعروضة 12 تحذيراً كحد أقصى تُقطع البقية في القائمة الداخلية.
نوع غير مدعوم أوtarget فارغ صف غير صالح يبقى في التقرير كـ INVALID_CSV_ROW.
رأس خاطئ أو لا صفوف بيانات ملف مرفوض LoadException.

العيّنة الجاهزة samples/inputs.csv تحوي 10 صفوف: 8 صالحة CSV و2 غير صالحين، وتُستخدم لاختبار بقاء الصفوف غير الصالحة دون تقييم.

٦. طبقة التشغيل والتزامن

٦.١ مسبح الخيوط

  • عدد العمال الافتراضي: DEFAULT_WORKERS = 4.
  • العدد الفعلي: min(maxWorkers, max(1, total))، وصفر عناصر يعني صفر عامل.
  • AtomicInteger cursor يضمن أخذ كل عنصر بواسطة عامل واحد بالضبط.
  • مصفوفة ItemResult[] تُحفظ فيها النتائج بمؤشرها الأصلي، فتبقى قائمة النتائج مرتبة رغم التزامن.
  • يُنتظر انتهاء المهام عبر Future.get()، ثم shutdown() وawaitTermination(5s) وإلا shutdownNow().

٦.٢ الأحداث والقياس الحيّ

يعرّف ScanEvents ثلاثة سجلات: ScanStartedEvent، ScanItemEvent، وScanFinishedEvent. يستقبل ScanObserver هذه الأحداث، وتنفّذ الواجهة ScanUiBridge لترجمتها إلى تحديثات واجهة عبر Platform.runLater. زمن كل عنصر يُقاس بـ nanoTime ويُقصّ إلى 1ms على الأقل حتى يظهر بوضوح في العرض.

٦.٣ عزل الأخطاء

الحالة المعالجة
CheckUnavailableException تُحوَّل إلى NotVerified(code, message).
أي Throwable آخر داخل عامل يُعزل كـ NotVerified / RULE_EXCEPTION ولا يُسقط الدفعة.
صف CSV غير صالح يُعاد مباشرة دون استدعاء القواعد.
AI غير متاح يُعيد Optional.empty() ولا يغيّر الدرجة.

٧.٢ الشريط الإرشادي داخل التطبيق

المفتاح النص المعنى
A · NAVIGATION Switch workspaces and read live scan status. التنقل بين المساحات وقراءة الحالة الحية.
B · INPUT Enter one signal or load a CSV batch for local rules. إدخال إشارة أو تحميل دفعة CSV.

٧.٤ المشهد ثلاثي الأبعاد ThreadCore

يبني المشهد SubScene بحجم 400×430 بكاميرا منظورية وزاوية رؤية 30. الأرضية 11.8×6.8 بوحدة استقبال على اليسار، وأربعة أبراج عاملين في المنتصف، ومنصة أرشفة بـ12 خانة على اليمين. الكابلات أنابيب ووصلات كروية، والحزم كرات تُلوَّن حسب النتيجة: أحمر للعالي، برتقالي للمتوسط، أخضر للمنخفض، ورمادي لغير المحسوب. خط مسح متحرك وشريط تقدم يعكسان نشاط الفحص.

الكاميرا الحالية: نظرة علوية مباشرة (top-down). الهدف (0.15, 0.62, 0.35) والعين (target.x, 24, target.z + 0.01). الإزاحة الصغيرة جداً في محور z تمنع انحناء دالة lookAt عند النظرة الرأسية، مع الحفاظ على استقامة اللوحة بلا ميلان.

٨.٣ حزمة model — السجلات والأنماط

الملف الوظيفة تفاصيل مهمة
ScanItem.java وحدة عمل مُرقّمة. (index, rowNumber, kind, target)؛ rowNumber اختياري للمفرد.
ScanInput.java وصف إدخال خفيف. (kind, target, rowNumber) قبل تحويله إلى ScanItem.
TargetKind.java نوع الهدف. URL أو MESSAGE.
RiskLevel.java مستويات الخطورة. LOW / MEDIUM / HIGH؛ الدرجة المنخفضة ليست ضمان أمان.
Finding.java قاعدة اشتركت مع دليلها. (ruleId, title, points, evidence) مع نسخ غير قابل للتعديل للقائمة.
ScanOutcome.java نتيجة عنصر واحد. sealed interface بفرعين Scored وNotVerified؛ الفرع الأخير لا يُحوَّل إلى LOW.

٩. معالجة الأخطاء ودلالة Not Verified

الكود المصدر المعنى
EMPTY_INPUT RuleSet مدخل فارغ بعد القصّ.
INVALID_URL RuleSet مخطط غير مدعوم، أو لا مضيف، أو Uri غير قابل للتحليل.
INPUT_TOO_LONG RuleSet تجاوز 2048 للرابط أو 5000 للرسالة.
INVALID_CSV_ROW CsvLoader نوع غير مدعوم أو خلية target فارغة.
LoadException CsvLoader ملف مفقود، حجم/ترميز/رأس غير مقبول، أو لا صفوف بيانات.
API_KEY_MISSING ExternalApiEvaluationService محاكاة فقدان مفتاح API.
API_RATE_LIMITED ExternalApiEvaluationService محاكاة HTTP 429.
API_TIMEOUT ExternalApiEvaluationService محاكاة انتهاء المهلة.
API_INVALID_RESPONSE ExternalApiEvaluationService محاكاة استجابة غير صالحة.
RULE_EXCEPTION ScanEngine استثناء غير متوقع داخل عامل، معزول عن بقية الدفعة.
قاعدة مهمة: Not Verified تعني «لم نستطع التحقق»، وليس «آمن». لذلك لا تُحوَّل إلى LOW في أي مكان في النظام، وتُعرض في الواجهة بلون رمادي محايد وبنص صريح.

١٢. القيود والعمل المستقبلي

العنصر الحالة الحالية ما المطلوب لتطويره
التحقق الخارجي عبر API مُحاكى فقط في Option B. كتابة طلب HTTP داخل وضع AVAILABLE، مفتاح API، وعرض النتيجة.
شرح AI بنية قابلة للتوصيل تُعيد Optional.empty(). ربط نموذج أو خدمة، مع الحفاظ على كونه ثانوياً لا يغيّر النقاط.

بروتوكولات أخرى ftp/mailto/javascript تُرفض. توسيع RuleSet إن كان مطلوباً.
الروابط النسبية //host غير مدعوم. إضافة تطبيع إضافي للمدخل.
عرض 3D علوي مباشر حالياً. يمكن ضبط زاوية متوسطة عبر eye = (0, 19, 6).
